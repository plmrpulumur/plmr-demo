# PLMR V.29 — DEMO PRODUCT AVAILABILITY

PLMR V.29 is the first integer-series development release after the immutable `PLMR V.28.6.Final` baseline.

## Scope

Demo top-level product availability is intentionally narrowed. The following products remain visible and active:

- Pergola
- Rolling Roof (Retractable)
- Bioclimatic (Tilt)
- Eco-Bioclimatic (Tilt)

The following products remain visible but are natively disabled and visually muted in the demo selector:

- Sürme
- Giyotin
- Zip Perde
- Kapı
- Sabit Doğrama
- Katlanır Cam

This release does not remove or rewrite the underlying standalone product engines, canonical state, Technical2D, PDF/DXF, persistence, Supabase or product schemas. The restriction is a demo UI availability policy only.

## Baseline and runtime identity

- Immutable source baseline: `PLMR V.28.6.Final`
- Release: `PLMR V.29`
- Runtime VERSION: `29`
- Build: `10.29-r29`
- Host/P3DV bridge: `plmr-p3dv-host-bridge-v29`
- Service-worker cache: `pulumur-pwa-v10_29_r29`

Accepted geometry/state/export behavior from V.28.6.Final must remain unchanged.
